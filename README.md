# IVYSKY: WORLD OF LIFE

This repository now contains a richer browser-based life-sim prototype inspired by open-world city life games, but built with original names, branding, cities, and systems.

## What is included

- A stylized open world with Nigeria and a fictional Aurelia Union
- Major city travel and district-based exploration
- Original character, business, and vehicle systems
- Jobs, property tracking, business income, and fame progression
- Time-of-day and weather simulation
- NPC movement and world interaction points
- Cheat entry for `MONEYMAN` that adds $12 billion to money and bank balances

## How to run

From the repo root:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Controls

- Move: WASD / Arrow Keys
- Interact: E
- Map: M
- Phone: P
- Vehicle: V
- Cheat code: MONEYMAN

## Scope note

This is still a browser prototype and not a full AAA production game. It serves as a playable vertical slice and a foundation for building a larger, more advanced version in Unity, Godot, or Unreal.
