# IVYSKY: WORLD OF LIFE

This repository now contains a playable browser vertical slice for an original open-world life simulation concept.

## Play

Open `index.html` in a browser, or run a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Included vertical slice

- A top-down explorable world with roads, districts, waterfront, transit and landmarks.
- Two-country travel: Nigeria has exactly five represented major cities; the fictional Aurelia Union has seven cities including MEGA CITY, MIAMI, GETHHO, LUXURY VILLA, HILL TOP HILLS, IVYSKY CITY and SAMARITAN.
- Original IVYSKY branding, characters, locations, vehicle names and world concepts.
- Walk and drive modes, a vehicle garage, mission tracking and interactive dealership/metro landmarks.
- Smartphone, world map, property, business and vehicle panels.
- Dynamic clock, weather display, cash/bank balances and local save feedback.
- A foundation for expanding the prototype into a full 3D game in an engine such as Godot, Unity or Unreal.

This is an intentionally scoped browser prototype rather than a complete AAA open-world game. The production-scale version would require an engine, 3D art pipeline, streaming world technology, animation, audio, online safety design and a much larger development team.
